# Трекер доходов и расходов

Веб-приложение (SPA) для учёта личных доходов и расходов. Работает полностью в браузере,
без серверной части и авторизации — все данные хранятся локально на устройстве пользователя.

Реализовано по техническому заданию [`tracker-tz.md`](./tracker-tz.md).

## Стек

- **TypeScript** (strict), **React 18**, **Vite**
- **MUI (Material UI)** — UI и тема (светлая/тёмная/системная)
- **Zustand** — управление состоянием + синхронизация с `localStorage`
- **React Hook Form** + **Zod** — формы и валидация
- **Recharts** — графики
- **dayjs** — работа с датами
- **React Router** — маршрутизация

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # dev-сервер (http://localhost:5173)
npm run build      # проверка типов + production-сборка
npm run preview    # предпросмотр production-сборки
npm run lint       # ESLint
npm run format     # Prettier
npm test           # тесты (Vitest)
```

## Возможности

- **Операции (CRUD):** доходы и расходы с суммой, категорией, датой, комментарием и тегами.
- **Поиск и фильтры:** по комментарию/тегам, типу, категории, диапазону дат и сумм; сортировка по дате и сумме; пагинация.
- **Категории и теги:** встроенный набор + пользовательские категории с цветом; защита от удаления категории с операциями (перенос операций).
- **Дашборд:** баланс, доходы/расходы за период, динамика по месяцам, разбивка по категориям, выбор периода (месяц/квартал/год/произвольный).
- **Бюджеты и лимиты:** лимит на категорию или общий, индикатор прогресса, предупреждение о превышении.
- **Повторяющиеся операции:** правила (ежедневно/еженедельно/ежемесячно/ежегодно), автогенерация пропущенных операций при запуске, пауза/редактирование/удаление.
- **Импорт/экспорт:** полный бэкап в JSON (с валидацией при импорте), экспорт операций в CSV.
- **Тёмная тема** с сохранением выбора и режимом «системная».

## Архитектурные решения

- **Слой хранения** (`src/storage`) инкапсулирован за интерфейсом `DataRepository`, что позволяет заменить `localStorage` на `IndexedDB` без изменений в остальном коде.
- **Валидация при загрузке:** повреждённые данные в `localStorage` не ломают приложение — выполняется безопасный откат к пустому состоянию.
- **Аналитика** (`src/lib/analytics.ts`) вынесена из компонентов и покрыта unit-тестами.
- Маршруты: `/`, `/transactions`, `/categories`, `/budgets`, `/recurring`, `/settings`.
